## Klip video (±25 detik, tanpa suara)

Video di X diputar otomatis **tanpa suara**, jadi klip ini tidak memakai narasi. Ceritanya disampaikan lewat **teks di layar (caption)** dan perubahan di halaman. Alurnya mengikuti isi post: kalimatnya dulu, lalu enam makna, lalu link.

| Detik | Layar | Caption di layar |
|---|---|---|
| 0–3 | Docs → tab **One sentence**, mode **Plain**. Zoom ke kartu pertama. | **"I didn't say she stole it."** |
| 3–5 | Kursor klik tombol **Mabarint**. Kata **I** langsung menebal. | **How should it sound?** |
| 5–20 | Scroll pelan melewati 6 kartu. Berhenti ±2 detik di tiap kartu supaya kata tebalnya terbaca (I → didn't → say → she → stole → it). | **Same sentence. 6 contexts.**<br>lalu **Meta's Muse Spark moves the stress.** |
| 20–23 | Hover pill *Stress: she* sampai alasannya terlihat. | **…and explains why.** |
| 23–26 | Kartu penutup: logo Mabarint di latar gelap. | **Mabarint · built with Meta Muse Spark**<br>**mazharrasyad.tech/mabarint** |

**Cara membuatnya di Windows 11 (gratis):**
1. **Rekam layar:** buka **Snipping Tool** → mode **Record**, lalu pilih area browser saja. Sebelumnya, set zoom browser ke 125% dan tutup popup Guide.
2. **Edit:** buka file rekaman di **Clipchamp** (sudah terpasang di Windows 11):
   - Potong bagian yang tidak perlu.
   - Tambahkan caption lewat menu **Text**, sesuai tabel di atas.
   - Untuk kartu penutup, tambahkan background warna gelap + teks.
   - Kalau scroll terlalu lambat, percepat bagian itu 1,5×.
3. **Export:** MP4 1080p. Untuk rasio, pilih **16:9** (lebih mudah, karena halaman Docs lebar) atau **1:1**. Kalau 1:1, crop ke area kartu.

**Alternatif:** klip ini bisa langsung dipotong dari video demo 3 menit (segmen 0:00–0:50), lalu captionnya ditambahkan. Narasinya tidak terdengar, karena orang menonton di X dalam mode tanpa suara.
